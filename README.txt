FILES
- index.html: website structure and personal birthday letter
- style.css: romantic pink/red styling and responsive layout
- script.js: letter button, surprise blessing and floating hearts
- our-photo-1.jpg and our-photo-2.jpg: your supplied photos

OPEN IN VS CODE
1. Extract this ZIP.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select this extracted folder.
4. Optional: install the "Live Server" extension.
5. Right-click index.html and choose "Open with Live Server".
6. To change the letter, edit the text inside index.html and save.

SEND THROUGH WHATSAPP — BEST WAY
A. To send the project itself: attach this ZIP as a Document. The recipient will need to extract it and open index.html.
B. To send a tap-to-open website link:
   1. Visit https://app.netlify.com/drop in your browser.
   2. Sign in or create a free Netlify account if prompted.
   3. Extract this ZIP first. Drag the extracted folder (or its files) into the Netlify Drop upload area.
   4. Wait for deployment and copy the public website URL Netlify provides.
   5. Open WhatsApp, paste the public URL into her chat and send it with a sweet message.
   6. Test the URL on your phone before sending it.
Note: The ZIP link is a download, not the published website. You must publish the files to get a public website URL. Photos are included in the folder and will display when the website is hosted with all files.
